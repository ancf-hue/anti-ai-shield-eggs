# 🥚 3D Egg Catcher — Ловец Яиц

[![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow?style=flat&logo=javascript)](https://developer.mozilla.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat)](LICENSE)

---

## 🎮 Игровой процесс

Вы управляете корзиной, которая движется по арене. С неба падают яйца — ваша задача поймать их в корзину. Каждое разбитое яйцо приближает конец игры!

### 🕹️ Управление

| Действие | Клавиши |
|----------|---------|
| Движение корзины | `↑ ↓ ← →` или `W A S D` |
| Вращение камеры | `Мышь` (зажмите и двигайте) |
| Пауза / Сброс фокуса | `ESC` |

### 🎯 Цель игры

- Собирайте как можно больше яиц 🥚
- Не допускайте падения 10 яиц на землю 💔
- Игра становится быстрее со временем ⏱️

---

## ✨ Особенности

- 🎮 **3D-графика** на базе Three.js
- 🔊 **Звуковые эффекты** (сбор, разбитие, проигрыш)
- 🎥 **Свободная камера** с вращением 360°
- 📱 **Адаптивный дизайн** под любые экраны
- 💳 **Система поддержки** с копированием номера
- 🏆 **Отслеживание времени и скорости**

---

## 🛠️ Технологии

- [Three.js](https://threejs.org/) — 3D-движок
- Native JavaScript (ES6)
- Web Audio API — генерация звуков
- Pointer Lock API — управление камерой
